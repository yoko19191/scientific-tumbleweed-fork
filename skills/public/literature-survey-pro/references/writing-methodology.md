# 写作方法论

本文件定义综述写作的核心方法论，在 Phase 3 (Write) 开始时加载。

---

## 1. Introduction 的 7 段漏斗结构

Introduction 必须遵循由大到小、由浅入深的漏斗结构，各部分比例如下：

| 段落 | 比例 | 内容 | 写作要点 |
|------|------|------|---------|
| Background | 5% | 大背景，课题为何重要 | 面向大众读者，通俗引入，不超过 2-3 句 |
| Research field | 5% | 具体研究方向 | 引入专有名词，完成从社会热点到专业领域的过渡 |
| Mini lit review | 25% | 已有研究回顾 + Research gap | 按主题/结论分组，**禁止逐篇列举**；必须包含 "however" 转折 |
| Significance | 20% | 本综述存在的必要性 | 解释 gap 为何重要，可与 mini lit review 合并写作 |
| Research questions | 25% | 具体研究问题 | 2-4 个可回答的 RQ，说明本文如何解决 |
| Contribution | 15% | 本综述的贡献 | 理论贡献 + 实践贡献，全文亮点的浓缩 |
| Overview | 5% | 章节路线图 | 告诉读者各章节涵盖什么，承上启下 |

### However Test

Mini lit review 部分**必须**有清晰的 "however" 转折：
- 转折前：构建已有研究基础（用权威文献）
- 转折后：论证本综述存在的必要性（指出 gap）
- 如果找不到自然的 "however"，说明 gap 论述不够清晰 → 重写

### 1大2小3个点 验证

写完 Introduction 后自检：
- **1 大**：大背景是否扎实？（不空泛、不冗长）
- **2 小**：小领域 + 小综述是否清晰？（专业术语引入时机恰当）
- **3 个点**：出发点（为什么做）、独创点（和前人有什么不同）、贡献点（发现了什么）是否完整？

### 引用策略

- 开头段落：用权威文献（高引用、领域奠基性工作）
- 中段 mini lit review：用近期文献（近 3-5 年）
- Gap 处：用精准相关文献（直接支撑 gap 论述的工作）

## 2. 八种叙事模板

根据 Scope 阶段选定的叙事角度，驱动全文故事线：

### a. 新现象
- **叙事弧**：现象 X 兴起 → 学术研究稀缺 → 本文探索理论成因
- **过渡短语**：「随着...的兴起」「然而，针对该现象的系统性研究仍然有限」
- **适用场景**：新兴技术、新社会现象、新发现的生物学机制

### b. 新人群/新场景
- **叙事弧**：现象 X 已被广泛研究 → 但在特定人群/场景中尚待探索 → 本文填补空白
- **过渡短语**：「尽管...已在...中得到充分研究」「在...领域的应用仍然不足」
- **适用场景**：跨地域/跨人群的研究迁移

### c. 新发展
- **叙事弧**：现象 X 发生了质变 → 旧研究框架不再适用 → 本文用新框架重新审视
- **过渡短语**：「近年来...经历了根本性转变」「传统方法未能捕捉到...」
- **适用场景**：技术范式转换、方法论革新

### d. 两面性
- **叙事弧**：现象 X 存在争议 → 已有研究偏重积极面 → 本文探索多面性
- **过渡短语**：「...的积极影响已被广泛记录」「然而，潜在的...风险尚未得到充分关注」
- **适用场景**：有争议的技术/方法/政策

### e. 矛盾性
- **叙事弧**：对现象 X 的研究结论相互矛盾 → 缺乏统一解释 → 本文提出整合框架
- **过渡短语**：「关于...的研究结论并不一致」「一些研究支持...而另一些则发现...」
- **适用场景**：实验结果不一致、理论争论

### f. 分支整合
- **叙事弧**：研究分化为多个分支 → 各自独立发展 → 本文整合多分支视角
- **过渡短语**：「...的研究已分化为若干独立方向」「尚缺乏将...与...统一考虑的综合框架」
- **适用场景**：多学科交叉、多方法论并存

### g. 领域渗透
- **叙事弧**：方法 X 在领域 A 成熟 → 领域 B 有类似需求 → 本文探索迁移可能性
- **过渡短语**：「...在...领域已取得显著成功」「这些方法对...领域具有潜在的借鉴价值」
- **适用场景**：方法迁移、跨领域应用

### h. 跨学科
- **叙事弧**：领域 A 和 B 各自发展 → 交叉点出现 → 本文构建跨学科框架
- **过渡短语**：「...与...之间的联系日益受到关注」「跨学科视角为理解...提供了新的可能」
- **适用场景**：学科融合、新兴交叉领域

## 3. 反模式检测规则

写作过程中必须主动检测并避免以下反模式：

### 列举反模式（最严重）
- **症状**：「A 等人提出了 X。B 等人提出了 Y。C 等人提出了 Z。」连续 3+ 句以作者名开头
- **修复**：按概念/方法/结论分组，用主题句统领，引用作为证据而非主语
- **正确示例**：「基于注意力机制的方法已成为主流范式 \citep{a2020,b2021,c2022}，其中...」

### Hedge 泛滥
- **症状**：每句都有 "may"、"might"、"could"、"possibly"
- **修复**：区分确定性层级——有强证据时直接陈述，仅在真正不确定时使用 hedging

### 谄媚语言
- **症状**：「这项开创性工作」「这一突破性发现」
- **修复**：中性描述——「该工作引入了...」「实验结果表明...」

### 缺失过渡
- **症状**：段落之间没有逻辑连接，读者需要自行推断关系
- **修复**：每段末尾必须有前向指针（递进/因果/转折/对比）

## 4. 段落结构模板

每个正文段落遵循四层结构：

```
主题句（对该主题的核心主张）
  → 证据簇（2-4 个引用支撑，按共识/分歧组织）
  → 分析（证据意味着什么，不仅仅是说了什么）
  → 过渡（桥接到下一段或下一节）
```

**示例**：
```latex
Transformer-based architectures have fundamentally reshaped the landscape of
natural language processing \citep{vaswani2017attention}. Subsequent work
demonstrated their effectiveness across diverse tasks, including machine
translation \citep{devlin2019bert}, text generation \citep{radford2019gpt2},
and question answering \citep{raffel2020t5}. Notably, these models share a
common reliance on self-attention mechanisms, yet differ significantly in
their pre-training objectives and architectural choices. However, the
computational cost of full self-attention scales quadratically with sequence
length, motivating a parallel line of research on efficient attention
variants (Section~\ref{sec:efficient}).
```

## 5. 主题章节写作规范

每个主题章节（Phase 3 中的 Thematic Section）必须包含：

1. **开头段**：1-2 段介绍该主题的动机和范围
2. **方法/发现分组**：按概念而非论文组织，每组一个段落
3. **对比表格**：至少 1 个 `booktabs` 风格的对比表（方法/数据集/指标/创新点）
4. **局限性段**：该主题方向的共性局限
5. **过渡段**：桥接到下一个主题章节

### 对比表格写作规范

- 使用 `\begin{table}[H]` + `booktabs`（`\toprule`, `\midrule`, `\bottomrule`）
- 列设计：Reference | Category | Key Innovation | Dataset/Context | Main Result
- 表标题放在表格上方（`\caption{...}` 在 `\begin{tabular}` 之前）
- 每个表格必须在正文中被引用（`Table~\ref{tab:...}`）
